# Model card

MarsTerrain is a research demonstration of semantic segmentation in historical Curiosity rover imagery. It is not a rover navigation or safety controller, and terrain class alone does not establish traversability.

The candidates predict soil, bedrock, sand, or big rock; 255 denotes an ignored reference pixel and is not a predicted terrain class. Models were trained using audited AI4Mars train data and compared against a disjoint validation split. Details, source revision, split limitations and licensing are in [the dataset card](dataset_card.md); configurations and actual validation results are in [the experiment record](experiments.md).

The selected candidate is a scratch-initialized MobileNetV3-small encoder with a compact skip decoder, trained in stages on up to 4,096 clean training images. The checkpoint SHA-256 is `d8c8ceb7dc2a535aeeb0b6246fc22d4f6bab306dff32fa1664476af9c821ca8f`. Full validation mIoU is 0.6312, with per-class IoU 0.7111 / 0.8808 / 0.6935 / 0.2395 in class order; big rocks remain difficult. The input is 256 × 256 RGB with values divided by 255; ImageNet mean/std normalization is part of the model even though its weights were initialized from scratch. The frozen protocol is in `experiments/frozen-model.json`. The frozen expert `test_min3` evaluation yielded mIoU 0.6581 on 287 images with valid labels (35 of 322 were entirely ignored); per-class IoU was 0.8463 / 0.8104 / 0.7692 / 0.2066. Only 4,852 valid pixels were labeled big rock, so its estimate is fragile. The test covered 7,310,367 valid pixels and 61.13% of pixels in evaluated images were ignored. See the experiment record for the confusion matrix, class supports and interpretation. The model is exported as a 4,385,772-byte ONNX artifact and runs locally in the browser and Python. It is not yet deployed publicly.
